These nine candidate assets first remove the obsolete circular mark and then replace it with the complete authoritative symbol cropped from `public/images/brand/omi-logo.png`. The black outer form, cyan circle and white droplet therefore come from one master; the cyan band is visible on both sides and continues along the lower arc.

They are previews only and are not referenced by the website. Production assets and gallery videos remain unchanged until approval.

Validation rules:

- Product and gallery canvas dimensions are unchanged.
- Every pixel outside the original circular-symbol rectangles is copied from the source asset without alteration.
- The `omi` wordmark, capacity, `AGUA MINERAL`, slogan, gold seal, bottle, background and lighting remain from the original assets.
- The symbol keeps each existing label footprint and the same contextual transform as its `omi` wordmark, so lockup alignment, page layout and CSS will not change when these candidates are approved.
