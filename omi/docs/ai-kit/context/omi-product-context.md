# OMI Product Context

Plantilla auxiliar. Los formatos y datos confirmados se consultan en `docs/agents/OMI_BUSINESS_CONTEXT.md` y los activos en `docs/image-agents/ASSET_MANIFEST.md`.

Centraliza aquí formatos, nombres, capacidades, materiales y assets oficiales.

## Regla
Nunca inferir un formato o especificación a partir de una imagen si no está validado.

## Campos por producto
- id
- nombre comercial
- capacidad
- tipo de envase
- dimensiones
- material
- imagen oficial
- uso recomendado
- estado: borrador/aprobado

## Ejemplo de estructura
```yaml
- id: omi-xxx
  nombre: "Pendiente"
  capacidad: "Pendiente"
  estado: borrador
```
