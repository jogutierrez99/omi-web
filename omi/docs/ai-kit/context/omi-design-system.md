# OMI Design System

## Principios
- Producto protagonista
- Alto contraste y legibilidad
- Secciones con ritmo visual distinto
- Evitar páginas monótonas
- Animación sutil y funcional

## Tokens sugeridos
Implementar mediante variables CSS o el sistema de tokens ya presente.
- `--omi-color-primary`
- `--omi-color-secondary`
- `--omi-color-accent`
- `--omi-bg`
- `--omi-text`
- `--omi-radius-sm/md/lg/xl`
- `--omi-space-*`
- `--omi-shadow-*`

## Responsive
Validar al menos:
- 390px
- 768px
- 1440px

## Animación
- respetar `prefers-reduced-motion`
- evitar animación ornamental excesiva
- priorizar entrada, foco y storytelling de producto
