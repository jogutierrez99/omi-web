# AI Architecture

```text
User Request
  -> Orchestrator
    -> Context
    -> Agent(s)
    -> Skill
    -> SOP
    -> Implementation
    -> Tests
    -> Visual QA
    -> Critic
    -> Delivery
```

El sistema debe reducir improvisación, no aumentar burocracia. Para tareas pequeñas, el orquestador puede omitir especialistas innecesarios.
