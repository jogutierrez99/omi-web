# Definition of Done

Una tarea no está terminada hasta cumplir lo aplicable:

## Código
- build correcto
- TypeScript sin errores
- lint correcto
- sin errores relevantes en consola
- código legible y sin duplicación innecesaria

## UX/UI
- desktop, tablet y móvil revisados
- sin overflow ni contenido cortado
- estados hover/focus coherentes
- navegación intacta
- identidad OMI respetada

## Accesibilidad
- HTML semántico
- contraste razonable
- navegación por teclado
- labels/alt cuando corresponda
- reduced motion respetado

## Performance
- imágenes optimizadas
- evitar JS innecesario
- no introducir regresiones evidentes de Core Web Vitals

## Entrega
- lista de archivos cambiados
- pruebas ejecutadas
- riesgos/deuda pendiente
