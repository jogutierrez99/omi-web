# SOP — Create Feature
1. Definir objetivo y criterios de aceptación.
2. Revisar arquitectura y componentes existentes.
3. Consultar contexto OMI.
4. Diseñar solución mínima.
5. Implementar.
6. Ejecutar build/lint/types/tests aplicables.
7. Revisar responsive y accesibilidad.
8. Actualizar documentación si cambia arquitectura.
9. Critic review.
