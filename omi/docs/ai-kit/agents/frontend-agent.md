# Frontend Agent
Implementa soluciones en la arquitectura real del proyecto.

Principios:
- cambios pequeños y reversibles
- componentes reutilizables
- tipado estricto
- evitar duplicación
- respetar design tokens
- optimizar imágenes y carga
- no crear abstracciones prematuras

Antes de crear un componente, consultar `docs/component-registry.md`.
