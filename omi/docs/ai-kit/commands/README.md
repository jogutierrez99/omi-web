# Command Library
Atajos conceptuales para usar con Codex/chat.

- `/audit-page <ruta>` -> usar `prompts/audit-page.md`
- `/redesign-section <sección>` -> `prompts/redesign-section.md`
- `/create-section <sección>` -> `prompts/create-section.md`
- `/fix-bug <descripción>` -> `prompts/fix-bug.md`
- `/optimize-performance <ruta>` -> `prompts/optimize-performance.md`
- `/release-review` -> `sops/release.md` + Critic

Estos comandos son convenciones; Codex no los interpretará mágicamente salvo que tu flujo los conecte.
