# Command Library
Atajos conceptuales para usar con Codex/chat.

- `/audit-page <ruta>` -> usar `prompts/audit-page.md`
- `/redesign-section <sección>` -> `prompts/redesign-section.md`
- `/create-section <tarea>` -> `prompts/create-section.md`: diseña, implementa e integra la sección y valida el resultado.
- `/fix-bug <descripción>` -> `prompts/fix-bug.md`
- `/optimize-performance <ruta>` -> `prompts/optimize-performance.md`
- `/release-review` -> `sops/release.md` + Critic

Estos comandos son convenciones de instrucciones del repositorio. `AGENTS.md` conecta `/create-section` con su prompt y exige usarlo también para tareas de creación o implementación de secciones expresadas en lenguaje natural, sin necesidad de escribir el comando. Los demás atajos requieren consultar el recurso indicado según la intención de la tarea.
