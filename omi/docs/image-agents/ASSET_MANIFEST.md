## Reglas

- No modificar ni sobrescribir estos originales.
- Crear masters y derivados en una carpeta de salida diferente.
- Registrar aquí cualquier activo oficial nuevo antes de usarlo como fuente superior.
- Si dos archivos discrepan, documentar el conflicto; no mezclar detalles silenciosamente.
- Para impresión, confirmar con el proveedor cuál es el arte final vigente.
