# Plantilla de encargo de imagen

No es obligatorio rellenar todo. El equipo debe obtener del proyecto lo que ya exista y preguntar solo por decisiones materiales.

```yaml
objetivo: ""
destino: hero_web | ficha_producto | redes | banner | impresión_mockup | impresión_final
mensaje_principal: ""
productos:
  - 500_ml
  - 1_5_L
  - 5_L
  - 18_L
operación: crear | editar | quitar_fondo | variar | ampliar | exportar
imagen_base: ""
referencias: []
cambio_solicitado: ""
debe_permanecer_idéntico: []
texto_visible_exacto: []
fondo: transparente | blanco | escena
medidas_px: ""
relación_aspecto: ""
formato_salida: PNG
notas: ""
```

## Información mínima para precisión alta

- Fotografía frontal nítida de cada formato real.
- Arte original de etiqueta, preferiblemente PDF/SVG/AI o PNG grande con alfa.
- Imagen aprobada que determine disposición y escala.
- Dimensiones finales y canal de publicación.
- Lista literal de cambios e invariantes.

## Para impresión final

Añade dimensiones físicas, sangrado, troquel, perfil de color, resolución objetivo y especificaciones del impresor. Sin esos datos el resultado solo puede marcarse como mockup.
