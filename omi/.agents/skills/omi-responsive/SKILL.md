# OMI Responsive

Validar 390, 768 y 1440 px como referencias mínimas.
Buscar:
- overflow horizontal
- saltos de texto
- CTA inaccesibles
- imágenes deformadas
- grid roto
- espaciado desproporcionado

Preferir layout fluido frente a parches por breakpoint.
