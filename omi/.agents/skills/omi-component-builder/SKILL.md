# OMI Component Builder

Consulta `docs/ai-kit/docs/component-registry.md` como inventario auxiliar y verifica siempre el código real antes de decidir.

Antes de crear:
- revisar registry
- buscar componente existente
- identificar API mínima

Al crear:
- props tipadas
- variantes explícitas
- accesibilidad
- estilos mediante tokens
- evitar lógica de negocio dentro de componentes puramente visuales
