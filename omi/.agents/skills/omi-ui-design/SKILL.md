# OMI UI Design
Úsala para crear o mejorar interfaces coherentes con OMI.

Procedimiento:
1. Leer `docs/ai-kit/context/omi-brand-context.md` y `docs/ai-kit/context/omi-design-system.md` como contexto auxiliar, contrastándolos con el repositorio y `docs/agents/PROJECT_RULES.md`.
2. Analizar jerarquía existente.
3. Reutilizar patrones antes de inventar.
4. Diseñar mobile-first.
5. Evitar monotonía usando variación de composición, no ruido.
6. Validar accesibilidad visual.
